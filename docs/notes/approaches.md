# アプローチのメモ

1. ベースライン
2. ROI処理
3. 人物をオブジェクトではなく顔で検出
4. オブジェクト検出で人物を列挙(低い信頼度) → 切り取って(ROI処理して)、ポーズ検出で人物に絞る
  - 実用に耐えうる信頼度でフィルター
  - 後ろ姿対策と、後のアプローチの体の向き検出を兼ねてでポーズ検出を採用
  - MediaPipe Pose Landmarkerが候補
  - 画像の切り出しは　固定サイズの非表示キャンバス + `createImageBitmap`でバウンディングボックスの範囲で指定で切り出し を実行して、ワーカー間では所有権移転で無駄を削減
  - 切り取る時は縦横それぞれ10%のマージンを持たせる
  - 元画像でマージンがない場合はレプリケーションでマージン補填
  - OpenCV.jsでレプリケーションをする場合はスコープ外宣言使い回しで上書きで、メモリ解放忘れずに実行
  - 人数が多い場合があるので、ワーカープールは必須
  - トラブルを防ぐため、ワーカープールの数は固定
  - 源流で`Promise.all`でバウンディングボックス列挙で出た候補を同時にワーカーマネージャーに投げる
6. 待機列は等間隔で並ぶことが多い → 距離ではなく顔、体の向きでグループ判定
  - おそらくこれでトイレで、連れに先に並んでもらっていた場合も解決する
7. 通行人の誤検出を避けるため前後の情報も組み合わせる

※ 連続稼働でOOMを防ぐため、前後や現在の検出結果はスコープ外で変数を宣言して使い回し
