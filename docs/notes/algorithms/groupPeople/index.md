# グループ判定アルゴリズム (groupPeople)

本モジュールは、画像から検出された人物群の位置座標（BoundingBox）、骨格座標（Keypoints）、および人物の向き（DirectionVector）を利用し、行列（キュー）の存在を認識した上でグループ（横並び＋前後跨ぎの関係）を判定するアルゴリズムです。

---

## アルゴリズム概要

全体の判定ロジックは、以下の3つの独立した子アルゴリズムによって順次構成されます。

1. **`estimateQueueLine` (列推定アルゴリズム)**
   - 人物群をバウンディングボックスのX座標順に並び替え、横幅の変化傾向に反するノイズを除外した上で、主成分分析（PCA）による直線軸と横幅勾配によるベクトル方向（起点 $\boldsymbol{p}_{\text{origin}}$ および方向単位ベクトル $\boldsymbol{d}$）を算出します。

2. **`groupByDistance` (距離・方向ベースのグループ化アルゴリズム)**
   - 推定された主直線 $\boldsymbol{L}$ の法線方向（横並び方向）および進行方向への射影座標を求め、連結成分判定 (Union-Find) により初期の横並びグループを算出します。

3. **`groupByOrientation` (体の向き・胴体四角形相互認識ベースのグループ化アルゴリズム)**
   - アプローチ2で生成されたグループを受け取り、各人物自身の身体サイズに応じた個別半径の扇形評価領域（Sector）を作成します。
   - 互いの扇形が相手の両肩・両腰から構成される「胴体四角形（Torso Quad）」と空間的に重複していること（AND条件／相互認識）を評価します。
   - グループ間において誰か1人でも相互認識されるペアが存在すれば、Union-Findによりグループ同士を丸ごと統合します。
