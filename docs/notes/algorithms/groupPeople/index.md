# グループ判定アルゴリズム (groupPeople)

本モジュールは、画像から検出された人物群の位置座標（BoundingBox）および人物の向き（DirectionVector）を利用し、行列（キュー）の存在を認識した上でグループ（横並びの関係）を判定するアルゴリズムです。

---

## アルゴリズム概要

全体の判定ロジックは、以下の2つの独立した子アルゴリズムによって構成されています。

1. **`estimateQueueLine` (列推定アルゴリズム)**
   - 全人物の中心座標の分散状況（PCA: 主成分分析）および視線・身体の向きベクトルを集計し、列全体の軸となる主直線 $\boldsymbol{L}$ を算出します。
2. **`groupByDistance` (距離・方向ベースのグループ化アルゴリズム)**
   - 推定された主直線 $\boldsymbol{L}$ の法線方向（横並び方向）および進行方向への射影座標を求め、連結成分判定 (Union-Find) により横並びのグループを算出します。
